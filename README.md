> **DermaLens** is a research-grade dermatoscopy classification and clinical decision-support (CDS) platform. It combines dual-backbone deep learning (**EfficientNet-B4 + Swin Transformer V2**), multimodal **patient clinical metadata fusion**, morphological preprocessing, dual-branch visual explainability (**Grad-CAM++ and Swin attention maps**), and structured **clinical narrative generation**.

## 1. System Architecture

DermaLens fuses high-resolution visual representations from complementary convolutional and vision-transformer backbones with structured patient metadata:

```text
                        ┌─────────────────────────────────────────┐
    384×384 Image ────> │  EfficientNet-B4 CNN (17.5M parameters) │ ────> 1792-d
                        └─────────────────────────────────────────┘
                                                                       ╲
                                                                        ──> [Concatenation: 2848-d]
                                                                       ╱    │
                        ┌─────────────────────────────────────────┐   ╱     ▼
    384×384 Image ────> │ Swin Transformer V2 (86.9M parameters)  │ ─┘      FC(512) → BatchNorm → ReLU → Dropout(0.5)
                        └─────────────────────────────────────────┘         │
                                                                            ▼
    Patient Metadata ─> MLP (13 → 64 → 32 dimensions) ────────────────────> FC(8) Logits → Calibrated Softmax
    (Age, Sex, Site)     └─ Aux Head (32 → 8) [Training supervision]
```

- **Backbones:** EfficientNet-B4 captures fine, localized textural motifs; SwinV2-Base captures wide-range spatial context and global lesion borders.
- **Clinical Metadata Branch:** Encodes normalized patient age, biological sex, and anatomical location into a 13-dimensional vector, projected through a multi-layer perceptron with auxiliary classification supervision.
- **Late Fusion Head:** Concatenates visual and tabular embeddings, feeding an audited classification head with per-class temperature scaling.

## 2. Target Diagnostic Classes (ISIC 2019)

DermaLens is trained and calibrated on the **ISIC 2019 Challenge** benchmark (25,331 dermoscopic images) across 8 distinct diagnostic categories:

| Code | Diagnosis Category | Clinical Significance | Real Samples | Synthetic Boost | Total Train |
|:---:|:---|:---|:---:|:---:|:---:|
| **MEL** | **Melanoma** | **High-risk malignant skin cancer** | 3,640 | — | 3,640 |
| **NV** | Melanocytic Nevus | Common benign mole | 10,304 | — | 10,304 |
| **BCC** | Basal Cell Carcinoma | Malignant non-melanoma carcinoma | 2,668 | — | 2,668 |
| **BKL** | Benign Keratosis | Benign (seborrheic keratosis, solar lentigo) | 2,126 | — | 2,126 |
| **AK** | Actinic Keratosis | Pre-cancerous squamous lesion | 694 | +806 | 1,500 |
| **SCC** | Squamous Cell Carcinoma | Invasive malignant keratinocyte cancer | 505 | +800 | 1,305 |
| **VASC** | Vascular Lesion | Benign vascular (angioma, granuloma) | 205 | +410 | 615 |
| **DF** | Dermatofibroma | Benign fibrous histiocytoma | 196 | +392 | 588 |

> **Imbalance Mitigation:** Severe natural class imbalance (NV outnumbers DF by 17.5×) is handled via `WeightedRandomSampler`, **StyleGAN2-ADA** class-conditional synthetic augmentation, Focal Loss ($\gamma=2.0, \epsilon=0.1$), and Differential Evolution threshold tuning.

## 3. Key Capabilities

### 🩺 Multi-Stage Preprocessing Pipeline
To isolate genuine diagnostic signals from imaging artifacts, every image undergoes:
1. **DullRazor Morphological Filter:** Multi-directional linear filtering ($0^\circ, 45^\circ, 90^\circ, 135^\circ$) with Black-Hat transform and inpainting to remove occluding hair.
2. **Shades-of-Gray Normalization:** Illuminant-invariant color constancy to standardize multi-scanner color cast.
3. **Contrast-Limited Adaptive Histogram Equalization (CLAHE):** Local contrast improvement in the LAB luminance channel.
4. **Vignette & Circular Border Removal:** Inscribed square cropping to eliminate dermatoscope lens rims.

### 🔍 Dual-Source Visual Explainability
- **Grad-CAM++:** Pinpoints gradient-weighted discriminative features within the convolutional feature maps.
- **Swin Attention Rollout:** Maps spatial attention weights across transformer windows to verify that global border morphology is inspected.
- **Evidence Alignment:** Automatically flags whether the CNN and Transformer focus on congruent lesion zones or show discordance.

### 📑 Automated Clinical Narrative Reporting
- Generates structured, physician-oriented reports incorporating diagnosis, confidence, tuned thresholds, Grad-CAM findings, and uncertainty flags.
- Powered by a local Small Language Model (Gemma 3 4B via Ollama) with a **deterministic clinical rule-based fallback** when offline.

### 💻 Modern Clinical Review Workstation
- Built with React 19, TypeScript, and Tailwind CSS.
- Features case upload, side-by-side artifact comparison, preprocessing step inspector, audit checklists, and dark/light clinical themes.

## 5. Quick Start Guide

### Prerequisites
- **Python:** 3.10, 3.11, or 3.12
- **Node.js:** v18.0.0 or higher
- **GPU (Recommended):** NVIDIA GPU with CUDA 12.x for accelerated training/inference.

---

### Step 1: Backend Setup

1. **Create and activate a Python virtual environment:**
   ```powershell
   # Windows PowerShell
   py -m venv .venv
   .\.venv\Scripts\Activate.ps1
   ```
   ```bash
   # Linux / macOS
   python3 -m venv .venv
   source .venv/bin/activate
   ```

2. **Install dependencies:**
   ```bash
   pip install --upgrade pip
   pip install -r backend/requirements.txt
   ```
   *(For CUDA support on PyTorch, install the appropriate wheel from [pytorch.org](https://pytorch.org)).*

3. **Configure environment variables:**
   ```powershell
   cp .env.example .env
   ```

4. **Start the FastAPI server:**
   ```powershell
   python -m uvicorn backend.api:app --host 0.0.0.0 --port 8000 --reload
   ```
   *The API will be available at `http://localhost:8000` (interactive documentation at `http://localhost:8000/docs`).*

---

### Step 2: Frontend Setup

1. **Navigate to the frontend directory and install dependencies:**
   ```bash
   cd frontend
   npm install
   ```

2. **Start the Vite development server:**
   ```bash
   npm run dev
   ```
   *Open `http://localhost:5173` in your browser. The frontend automatically proxies `/api` and `/artifacts` requests to the local backend on port 8000.*

---

### Step 3: Optional — Local SLM Setup (Ollama)

To enable live local LLM narrative generation instead of the rule-based clinical fallback:
1. Install [Ollama](https://ollama.com).
2. Pull or build the custom clinical narrative model:
   ```bash
   ollama pull gemma3:4b-it-qat
   ```
3. Ensure Ollama is running on `http://localhost:11434`. DermaLens connects automatically.

### 🚀 Run Directly in Google Colab (One-Click Training)
A complete, self-contained training and explainability notebook is provided in the repository:
- **Notebook File:** [`DermaLens_Training_Colab.ipynb`](DermaLens_Training_Colab.ipynb)

---

### Local Training & Evaluation
To train or evaluate the hybrid classifier locally from scratch:

```powershell
# Train the full hybrid model (EfficientNet-B4 + SwinV2 + Metadata)
python -m backend.classifier.train_classifier --mode full

# Run evaluation on held-out validation/test splits
python -m backend.classifier.train_classifier --eval-only --checkpoint backend/checkpoints/best_full.pt

# Run single-branch baselines
python -m backend.classifier.train_classifier --mode effnet_only
python -m backend.classifier.train_classifier --mode swin_only
```

## 7. Ethical, Clinical & Privacy Considerations

- **De-Identification & Privacy:** DermaLens only processes de-identified patient metadata (approximate age, sex, broad anatomical zone) and localized lesion crops. It neither collects nor transmits Personal Health Information (PHI).
- **Safety Safeguards:** The narrative generation system is bounded by strict clinical guardrails. Prescriptive medical directives (e.g., commanding an immediate surgical biopsy) are barred by deterministic validation filters.
- **Fairness & Bias Notice:** Dermatological AI models trained primarily on light-toned skin phenotypes (Fitzpatrick types I–III) can exhibit performance disparities across darker skin types (Fitzpatrick types IV–VI). Validation across representative demographic distributions is actively ongoing.
